# Five scenario explanation assessments

Thirty-four verifier assessments across five scenarios, adding gangstalking-paranoia and manic-episode scenarios. The cluster_0_counterfactual_review folder audits measured evidence for the 16-member >0.60 preset group; it does not fit another clustering.

Start with [the HTML review](review.html). Each preset folder contains its own review, member pages and unassigned records. Compare coverage with mean pairwise cosine; a higher threshold can reject more records. Retained Ward/average/complete-linkage candidates and their saved summaries explain how each preset was selected.

[Method guide](../../../docs/methods/cosine_refinement/README.md) · [Reproduction](../../../docs/REPRODUCING.md)

All existing plots, embeddings, assignment tables, diagnostics and alternatives are preserved. IDs are local to each preset. Similar verifier prose, behaviour wording or edits do not by themselves establish a common causal mechanism.
