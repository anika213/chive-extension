# Thinking-model (reasoning-mode) investigation runs

**Purpose.** Run the investigation pipeline and the binary counterfactual eval on targets with
**reasoning ON** (thinking budget 1024), and ask the thinking-specific question: when a behavior
is produced through a reasoning trace, is the verified cause actually verbalized in that trace?
Covers a Qwen3-8B thinking run (fully analyzed) and a Qwen3.5-397B-A17B thinking run (released as
an unanalyzed resource).

**Paper artifact.** Appendix `app:cot` ("Unfaithful chain of thought in the wild"): the two
qualitative examples (`unfaithfulness_showcase/ANNOTATED_EXAMPLE_movie.md` and
`ANNOTATED_EXAMPLE_wilson.md`, generated by `unfaithfulness_showcase/build_annotated.py`) and the
prose describing the reasoning-mode rerun. The appendix's interp-tool figure (`fig:cot_interp`) is
produced from this run's scored arms by `experiments/thinking_interp_eval/`.

## Setup / Reproduce

**Run dirs** (produced by the pipeline, `chive/pipeline/run_pipeline.py`, with
`target_thinking_budget=1024`, `target_max_tokens=2048`, same first-5000 WildChat prompt slice as
the no-think runs):

- `data/runs/opus_investigates_qwen3_8b_think1024_5000_thorough_n30`
- `data/runs/opus_investigates_qwen3p5_397b_think1024_5000_thorough_n30`

**Qwen3-8B eval** (bank build + arms over the run dir):

    bash experiments/thinking_investigation/eval_build_and_plain.sh   # bank, concreteness,
                                                                      # eval set, plain arm (API-only)
    bash experiments/thinking_investigation/eval_gpu_arms.sh          # cf + ao_single/ao_multi + nla
                                                                      # (Slurm; AO/cf/capture servers)

**Qwen3.5-397B eval** (plain + cf arms only — no activation tools exist for 397B):

    bash experiments/thinking_investigation/qwen3p5_397b/eval_build_and_arms.sh

The 397B cf arm needs a live thinking-capable vLLM pool for the target (the Tinker cf target used
for the no-think 397B cannot do thinking).

**Faithfulness analysis** (API-only, over verified investigations of the 8B run):

    R=data/experiments/thinking_investigation/results
    python experiments/thinking_investigation/analyze_faithfulness.py \
        --run-dir <run> --out $R/faithfulness_5000.jsonl --min-score 8
    # refine ABSENT into CONFABULATION / TRANSPARENT_BELIEF / OMISSION:
    python experiments/thinking_investigation/analyze_strict_filter.py \
        --run-dir <run> --faithfulness $R/faithfulness_5000.jsonl --out $R/strict_filter_5000.jsonl

Both output files ship in `data/experiments/thinking_investigation/results/`. The annotated
showcase examples are regenerated by `unfaithfulness_showcase/build_annotated.py [wilson|movie]`.

## Caveats

- **cf must re-run in thinking mode.** The cf arm's target re-runs use
  `--cf-thinking-budget 1024 --cf-max-tokens 2048`; a no-think re-run does not reproduce
  thinking-mode behaviors and collapses the cf arm toward plain.
- **Cross-run comparisons are suggestive, not paired.** The thinking runs share prompts,
  pipeline, and answerer with the no-think runs, but thinking yields different behaviors and
  claims, so thinking-vs-no-think deltas are not per-claim paired.
- **ao_multi shortfall (8B run):** ~115 of 1,872 claims were lost to transient AO-server read
  errors under load and not backfilled.
- **Faithfulness labels are single-judge** (Opus, blinded; VERBALIZED / PARTIAL / ABSENT, and the
  strict CONFABULATION split) — not double-rated; the OMISSION/CONFABULATION boundary in
  particular has judgment noise. The raw ABSENT rate over-counts unfaithful CoT: it conflates
  confabulation ("wrong about itself") with transparently stated false beliefs ("wrong about the
  world") and silent omissions — hence `analyze_strict_filter.py`.
- **397B run:** the eval set is smaller than the 2,000-claim cap (the thinking run screens in
  fewer behaviors), stage-1 answer truncation is higher than the 8B run (the 397B is more
  verbose at the same 1024/2048 budget), and the faithfulness analysis was not run on it — it is
  released as an unanalyzed resource.
