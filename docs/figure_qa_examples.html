If you want to ensure that your plotting function executes only once regardless of how many times a checkbox is checked or unchecked, you can use a flag variable to keep track of whether the plot has already been generated. This way, you can prevent the function from executing again after the initial plot creation.

Here's a basic example in Python using a simple GUI framework like `tkinter`, along with the `matplotlib` library for plotting:

```python
import tkinter as tk
from matplotlib import pyplot as plt

class PlotApp:
    def __init__(self, root):
        self.plot_created = False  # Flag to track if the plot has been created
        self.checkbox_var = tk.IntVar()

        self.checkbox = tk.Checkbutton(root, text="Generate Plot", variable=self.checkbox_var, command=self.on_checkbox_change)
        self.checkbox.pack()

    def on_checkbox_change(self):
        if not self.plot_created:
            self.create_plot()
            self.plot_created = True

    def create_plot(self):
        # Example plot
        plt.plot([0, 1, 2, 3, 4], [10, 20, 25, 30, 40])
        plt.title("Sample Plot")
        plt.ylabel("Y-axis")
        plt.xlabel("X-axis")
        plt.show()


if __name__ == "__main__":
    root = tk.Tk()
    app = PlotApp(root)
    root.mainloop()
```

### Explanation

1. **Flag Variable (`plot_created`)**:
